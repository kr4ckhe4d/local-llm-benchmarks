oracle-select: the temp-0 answer plus 5 samples (t0.6, top_p 0.95, top_k 20). The model
writes a differential test against the REAL stdlib function (edge cases + 300 seeded
random inputs, prints `MISMATCHES n OF total`). Candidates are ranked by that count,
then up to 8 fix rounds hill-climb on it, keeping the version with fewest mismatches.
Hidden checks are never used for selection; an answer importing the reference module
is voided.

Where 50/50 stops:

  difftest sees it, but no fix in ~40 attempts across runs removes it without breaking
  something else.
- textwrap long-word packing / empty input: no answer in ~50 has passed all 6.
  Best per-task across all corrected-prompt runs is 48/50 (urljoin 9/9 from
  select+repair) -- but that is picked with the hidden checks, not a method.

Next lever if pursued: when every candidate fails the test at the same line, fix
