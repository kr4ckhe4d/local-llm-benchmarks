Two kinds of failure, and only one is fixable by the model checking itself:
- SLIPS: one line wrong in a long function wrecks every output (csv `field = []`,
  urljoin `//` consumed twice, plan's urljoin parse). Sampled runs hit one in ~1 task
  in 5. Own tests catch them; select/repair remove them.
- MISUNDERSTANDINGS: shlex quoting, textwrap whitespace, urljoin dot_only. The model's
  tests encode the same mistake: real shlex.split passes 138/142 of its shlex tests,
  the model's wrong function 140; real textwrap 35/41, model answers 38. No self-check
  fixes these. The Nemotron review fixed one shlex case the hidden checks don't cover.

Greedy-path noise: MTP on/off and KV q8_0/f16 each move the temp-0 score by 1-2
checks with every other setting fixed. Treat single-run differences under ~2 as ties.

Harness bugs found and fixed on the way (all in commit history):
- code-quality-test.py extract_code paired fences wrongly after a ```text block.
- tests that do not compile now salvaged line by line; function redefinitions in
  tests stripped; test generation capped at 4096 tokens and deduped (glob tests
  looped ~250x on one assert at temp 0).
